# Kevin Parra — Portfolio

Personal portfolio for Kevin Parra, a Senior Frontend Engineer specializing in React, TypeScript, Next.js, and AI-powered products. It presents selected projects, technical skills, professional experience, and client work.

- **Live site:** [evinracher.github.io](https://evinracher.github.io/)
- **LinkedIn:** [linkedin.com/in/evinracher](https://www.linkedin.com/in/evinracher/)

## Run locally

Requirements: Node.js and npm.

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000). The development server reloads automatically when files change.

## Test and build

```bash
npm test
npm run build
```

The production build is generated in `build/`.

## Deploy

Run the deployment command from `main` or another source branch containing `package.json`:

```bash
npm run deploy
```

This creates a production build and publishes it to the `gh-pages` branch. In the repository settings, configure GitHub Pages to deploy from the `gh-pages` branch and the `/ (root)` folder.

React, JavaScript, CSS Modules, and GitHub Pages.
